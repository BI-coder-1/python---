第三课时：基础时域特征计算

1. 核心公式与 NumPy 代码的对应关系
   最小幅值：np.min(data)，最大负向振动。
   最大幅值：np.max(data)，最大正向振动。
   峰值幅度：np.max(np.abs(data))，取绝对值后找最大值。
   均值：np.mean(data)，检查直流偏移。
   平均绝对幅度：np.mean(np.abs(data))，取绝对值后求平均。
   总能量：np.sum(np.square(data))，平方后求和。
   平均能量：np.mean(np.square(data))，平方后求平均。
   RMS (均方根)：np.sqrt(avg_energy)，平均能量开根号。

2. 为什么我们要这样算？
   振幅与能量的区别：振幅反映的是波形的高低（可以正可以负），而能量必须用平方。因为音频波形有正有负，直接相加会相互抵消变成 0，平方后全变为正数，才能真实代表信号的能量大小。
   为什么计算平均能量？如果两段音频长度不同（比如 5 秒和 10 秒），10 秒的总能量肯定更大。除以采样点数得到“平均能量”，可以用来比较数字信号的平均强度（注意：人耳响度还受频率、录音增益等因素影响，不能完全等同于物理响度）。
   精度控制：在计算平方前，我们强制使用了 astype(np.float64)。当前数据已归一化到 [-1, 1]，平方不会溢出。转换为 float64 的主要目的是提高平方、求和等累计运算的数值精度；它不能保证所有数值永远不溢出。

3. 实际比较结果
   对比 0_0_1.wav 和 4_0_1.wav：
   峰值幅度：0.389 > 0.151
   平均能量：0.0034 > 0.00013
   RMS：0.058 > 0.011

结论：客观数据表明，0_0_1.wav 的整体幅度、平均能量和 RMS 均明显高于 4_0_1.wav。

4. 关于“能量”的单位
   这里计算的“能量”是相对数字能量（没有焦耳单位）。因为我们读取的音频是归一化到 [-1.0, 1.0] 之间的相对浮点数。如果需要计算真实声学的物理能量，需要结合麦克风的灵敏度、放大器的增益进行标定。
